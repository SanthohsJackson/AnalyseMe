# Stage: System Synthesis

The 'AnalyseMe' codebase consists of several modules designed for analyzing code repositories and generating specifications. The 'pipeline' module manages a code-to-spec pipeline, including model configuration and output rendering. The 'pipeline/parsers' module extracts code structure using Tree-sitter. The 'pipeline/nodes' module handles tasks like document validation and test generation. The 'pipeline/prompts' module defines prompt templates. The 'cli' module provides a command-line interface for repository interaction and pipeline management. The root module offers a script for launching the application and defines data structures for code analysis. Modules collaborate with each other, particularly the 'pipeline', 'pipeline/nodes', and 'cli' modules.
