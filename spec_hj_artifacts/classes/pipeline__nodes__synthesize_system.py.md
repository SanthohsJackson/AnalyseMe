**File:** pipeline/nodes/synthesize_system.py

## Purpose
Generate a system-level overview from module summaries using LLM prompts.

## Interfaces
### `synthesize_system` (function)
```
synthesize_system(state: PipelineState) -> dict
```
**Intent:** Aggregate module summaries into a comprehensive system overview using a language model prompt.

**Inputs:**
- state: PipelineState — the current pipeline state containing module summaries and other metadata
**Outputs:**
- dict — containing the system overview generated by the LLM

## Behavioral notes
- The function relies on the presence of 'module_summaries' in the state, defaulting to an empty list if absent.
- The 'repo_name' is derived from the 'repo_path' in the state, defaulting to 'unknown' if not provided.
