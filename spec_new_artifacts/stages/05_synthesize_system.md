# Stage: System Synthesis

The 'AnalyseMe' codebase consists of several modules designed for code-to-spec analysis. The 'pipeline' module manages the analysis pipeline, including interactions with language models and rendering outputs. The 'pipeline/parsers' module extracts code structure using Tree-sitter. The 'pipeline/nodes' module handles tasks like document validation, system overview generation, and repository data ingestion. The 'pipeline/prompts' module provides prompt templates. The 'cli' module offers a command-line interface for configuring and managing the pipeline. The main module serves as the entry point for executing the CLI application and provides data structures for code analysis. Collaborations occur between the main module, 'cli', 'pipeline', 'pipeline/nodes', and 'pipeline/prompts'.
