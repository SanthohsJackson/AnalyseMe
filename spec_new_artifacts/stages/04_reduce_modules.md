## pipeline/parsers
The 'pipeline/parsers' module is responsible for extracting code structure using Tree-sitter for various programming languages. It includes functions to determine programming languages from file extensions, retrieve Tree-sitter parsers, extract import paths, count lines of code, and build structured representations of code. It also provides functionality to extract class spans and parse files to analyze their structure.
