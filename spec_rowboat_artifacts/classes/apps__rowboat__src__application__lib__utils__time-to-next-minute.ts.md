# apps/rowboat/src/application/lib/utils/time-to-next-minute.ts

**File:** apps/rowboat/src/application/lib/utils/time-to-next-minute.ts  
**Language:** typescript

## Purpose
Provide utility functions to calculate time remaining until the next minute or hour.

## Interfaces
### `secondsToNextMinute` (function)
```
secondsToNextMinute() -> number
```
**Intent:** Calculate the number of seconds remaining until the next minute starts.

**Outputs:**
- number — the number of seconds until the next minute

### `minutesToNextHour` (function)
```
minutesToNextHour() -> number
```
**Intent:** Calculate the number of minutes remaining until the next hour starts.

**Outputs:**
- number — the number of minutes until the next hour
